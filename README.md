# Personal Portfolio Website

A clean, responsive personal portfolio website developed with **HTML5**, **Bootstrap 5**, and custom CSS. Deployed live using **Vercel** via **GitHub**.

## Author
* **Name:** Aiman Fatima
* **Degree:** BS Computer Science
* **Institution:** The University of Lahore

---

## Features
* **Bootstrap 5 Responsive Grid & Components:** Features responsive Navbar, Cards, Badges, Progress Bars, Alerts, and Buttons.
* **Sticky Navigation Bar:** Mobile-friendly collapsible menu with quick-jump anchor links.
* **Semantic HTML5 Markup:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags.
* **Academic & Skills Showcase:** Responsive HTML table for education history and styled progress meters for technical skills.
* **Project Showcase:** Interactive hover-lift cards featuring project details and GitHub link shortcuts.
* **Fully Responsive:** Tested across mobile, tablet, and widescreen desktop layouts.

* **Version Control:** Git, GitHub
